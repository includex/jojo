# 한국어 재번역

중국어 원문을 기준으로 Sol이 직접 번역한 파일입니다. `sol/a`, `sol/b`, `sol/c`는 원문 목록을 세 부분으로 나눈 작업이며, `sol/extra`는 기존 캐시에만 있던 메뉴·도움말·인물 열전 등의 추가 원문입니다. `sol/opening`에는 검토한 도입부가 있습니다.

- `baseline/translations.json`: 재번역 전 중국어→한국어 대응표.
- `baseline/dialogue-text.json`: 재번역 전 게임 대사 카탈로그.
- `baseline/scenarios.zip`: 재번역 전 복원 Python 소스. 줄 번호를 보존하여 다시 적용할 때 사용합니다.
- `context-reviews.json`: 기존 한국어가 같아 원문을 구별하기 어려운 문장의 장면별 검토 결과.
- `progress.json`: 실제 적용 범위와 남은 대응 검토 목록.

검증과 적용:

```sh
python3 tools/verify_sol_translation.py --require-complete
python3 tools/apply_sol_translation.py --apply
```

적용 도구는 이 프로젝트의 대사 카탈로그와 `jojo_mobile/sgccz-desktop/decompiled-python`의 문자열 리터럴을 갱신합니다. 프로그램 구조와 줄 번호가 유지되는지 검사하며, 원본 암호화 자산과 중국어 원문은 덮어쓰지 않습니다. 원본과 재번역본은 모두 보관됩니다.

장비·인물·책략 테이블은 원본 백업의 파일·필드 위치를 사용합니다. 서로 다른 원문이 같은 한국어로 오역된 경우도 구별합니다. 예를 들어 장억(張嶷)과 장익(張翼)의 이름을 각각 복원합니다. 수치와 데이터 구조는 원본과 같은지 검사합니다.

주요 용어는 주군(主公), 승상(丞相), 책략(策略), 공훈(功勋), 무력(武力), 통솔력(统率), 지력(智力), 민첩(敏捷), 운(运气), 순발력(爆发力), 회귀(回归), 지계(地系·土系)입니다. 대사의 호칭과 높임말은 화자와 상대에 맞춥니다. 도입부의 부하 대사는 “주군, 서두르셔야 합니다!”로 정했습니다.

이전 번역의 화면 캡처·픽셀 비교 자료는 이전 문구를 재현하는 증거이므로 새 번역의 픽셀 정답으로 사용할 수 없습니다. 새 텍스트용 글리프 리소스는 Gradle이 다시 생성합니다.
