방어구도 함께 착용하고 싶다면

다음 호출은 실제 무기 0과 방어구 70을 장착하는 실습입니다. 방어구는 슬롯 오프셋이 달라 압축 코드 2가 실제 ID 70을 뜻합니다. Lua 예제의 방어구 70 피해 감소를 시험할 때 이 설정을 사용할 수 있습니다.

실제 장비 0 + 방어구 70 · python
stage.setJoinEquip(0, 2, 0, 2, 0, 0)

인자 순서: 인물 ID, 무기 코드, 무기 레벨 값, 방어구 코드, 방어구 레벨 값, 보조구 코드. 무기·방어구 레벨 값 0은 0레벨 장비가 아니라 인물 레벨에 따라 자동 계산한다는 뜻입니다. 모든 슬롯에 같은 계산을 임의로 적용하지 말고 API 명세와 기존 예제를 확인하세요.
