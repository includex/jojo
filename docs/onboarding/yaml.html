학습 과정 / 초급 01

YAML로 장수 이름 바꾸기

인물 파일 하나에서 이름과 소개를 바꿉니다.

이번에 편집할 곳content/characters/0000.yaml
배울 것파일 저장과 빌드·재실행의 흐름을 익힙니다.

이번 과제

기존 장수 0의 이름을 “아린”으로 바꿉니다. 인물 추가·게임 제목·전투 규칙은 나중에 배웁니다. 이번에는 파일 하나만 수정합니다.

  1. content/characters/0000.yaml을 텍스트 편집기로 엽니다. 원본을 백업하거나 실습 복사본에서 작업합니다.
  2. 기존 name과 intro 줄의 값만 아래처럼 바꿉니다. id: 0과 나머지 항목은 유지합니다.
  3. 파일을 저장합니다. 실행 중인 게임을 닫고 프로젝트 루트의 터미널에서 아래 명령을 실행합니다.
  4. R_01 장면의 첫 대사를 넘겨 인물 0이 말하는 두 번째 대사와 인물 정보를 확인합니다.
부분 수정 · 파일 전체를 덮어쓰지 않음 · yaml
name: "아린"
intro: "북쪽 마을을 지키는 신참 기사."
저장소 루트에서 검사 후 실행 · sh
./gradlew :core:compileGameContent
./gradlew :desktop:run --args="--scenario=R_01"
성공하면 이렇게 보입니다

인물 데이터의 이름·소개가 달라집니다. 대사 문장 안에 직접 적힌 “조조”는 별도 텍스트이므로 자동으로 전부 바뀌지 않습니다. 그 문장은 초급 03에서 수정합니다.

새 게임으로 비교하세요

기존 저장에는 인물 이름·능력치 변경이 남을 수 있습니다. 첫 실습은 기존 세이브를 불러오기보다 새 상태로 시작해 확인합니다.

attack:45# 기본 공격 능력 값
키: 프로그램이 아는 항목명콜론 뒤 공백값: 여기서는 정수주석: 사람을 위한 설명
YAML의 문자열·정수·목록·매핑 · yaml
# 설명용 예제입니다. 아래 항목을 한 파일에 전부 붙이지 않습니다.
name: "기사 아린"       # 문자열
attack: 45              # 정수: 따옴표 없음
skillEffects: [106]     # 목록: 여러 ID를 담을 수 있음
learnLevels:            # 매핑: 다른 키 아래에 값이 들어감
  "0": 1                # 병종 0 → 습득 레벨 1
  "1": 1

이렇게 작성합니다

올바른 형태 · yaml
attack: 45
name: "검: 초급"
learnLevels:
  "0": 1

이렇게 쓰면 오류입니다

따라 쓰지 않을 오류 예제 · yaml
attack: "45"     # 정수 자리에 문자열
attack: 50       # 같은 키를 두 번 작성
learnLevels:
"0": 1           # 안쪽 항목의 들여쓰기 누락
extraPower: 10   # 규격에 없는 필드
  1. 탭 대신 공백을 사용합니다. 같은 깊이의 항목은 같은 칸에서 시작합니다. 실습은 YAML 2칸, Python 함수 안 4칸을 사용합니다.
  2. 자료형을 맞춥니다. 정수는 45, 문자열은 "아린", 불리언은 true/false입니다. 불리언은 해당 필드가 허용할 때만 씁니다.
  3. 값이 없는 것과 0은 다릅니다. 선택 필드를 생략하면 기본값을 사용합니다. 모르는 필드를 0으로 채우거나 null로 넣지 않습니다.
  4. 중복 키를 만들지 않습니다. 기존 learnLevels에 항목을 추가할 때 두 번째 learnLevels 블록을 만들지 않습니다.
  5. 오류는 한 번에 하나씩 고칩니다. 저장 후 다음 명령으로 검사하고, 실패하면 처음 나온 파일명과 항목을 확인합니다.
터미널 · 정적 YAML 검사 · sh
./gradlew :core:compileGameContent

BUILD SUCCESSFUL이면 구문·스키마 검사를 통과한 것입니다. “장비가 실제로 착용됐다”, “대사가 보인다”까지 증명하는 것은 아니므로 이후 화면 확인이 필요합니다.

JSON·Python·Lua는 YAML과 무엇이 다른가요?
형식이 프로젝트에서 하는 일처음 기억할 문법
YAML인물·장비·변수·규칙 선언콜론, 공백 들여쓰기, 목록의 하이픈
JSON대사 카탈로그·모듈 등록쌍따옴표, 쉼표, 중괄호. 주석과 마지막 쉼표 금지
Python장면·배치·대사 순서함수·조건문 들여쓰기. 지원되는 AST 문법만 실행
Lua선택적인 동적 전투 규칙function/end, return, 효과 목록
