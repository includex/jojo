배울 것코드 없이 이야기 문구를 바꾸는 첫 과제입니다.

이번 과제

R_01에서 처음 나오는 문장 하나를 바꿉니다. 이번 과제에서는 Python을 작성하거나 새 대사 ID를 만들지 않습니다.

R_01.py언제 말할지 정해져 있음
→
기존 대사 IDR_01.scene1.dialogue0001
→
카탈로그 문장이번에 바꿀 부분

작업 순서

  1. content/scenarios/dialogue-text.json을 엽니다.
  2. entries 안에서 R_01.scene1.dialogue0001을 찾습니다. 키 이름은 유지하고 오른쪽 문장만 아래처럼 바꿉니다.
  3. &101\n은 원래 화자와 줄바꿈 표기이므로 그대로 둡니다. 주변 항목과 구분하는 쉼표도 유지합니다.
  4. 파일을 저장하고 AST·리소스를 검사한 뒤 R_01을 실행합니다.
entries 안의 기존 한 항목 교체 · 주변 쉼표는 유지 · json
"R_01.scene1.dialogue0001": "&101\n북쪽 마을에서 소식이 왔다.\n함께 상황을 살펴보겠나?"
문장 검사와 장면 실행 · sh
./gradlew :core:exportScenarioAst :core:processResources
./gradlew :desktop:run --args="--scenario=R_01"
성공하면 이렇게 보입니다

R_01의 첫 대사가 새 문장으로 표시됩니다. 이후 장면은 원래 순서대로 계속 진행됩니다.
