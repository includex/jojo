배울 것유닛 ID와 위치, 등장 연출의 차이를 익힙니다.

이번 과제

기존 S_00 전투에서 적 둘과 아군 측 둘의 위치를 서로 바꿉니다. 이미 사용 중인 칸을 재사용하므로 새 지도·인물·모듈 등록 없이 좌표를 익힐 수 있습니다.

생성 배치와 등장 후 배치를 구분합니다

적 둘은 생성 목록의 x/y를 바꿉니다. 인물 0은 숨겨진 상태로 생성된 뒤 연출에서 여러 번 이동하므로, 아군 측은 조작 시작 직전의 마지막 이동 위치를 바꿉니다. 인물 32는 우군입니다.

좌표 관계를 보여주는 교육용 그림입니다. 실제 맵의 전체 크기·통행 지형을 그린 편집기는 아닙니다.

1. 적군의 생성 좌표 바꾸기

  1. content/scenarios/S_00.py에서 def scene0(): 안의 stage.createEnemy([를 찾습니다.
  2. 첫 항목 id: 146의 x를 9에서 10으로 바꿉니다. 다음 항목 id: 147의 x를 10에서 9로 바꿉니다. 둘 다 y는 11을 유지합니다.
  3. id·i·lv와 다른 유닛은 수정하지 않습니다. 아래는 두 항목만 발췌한 예이며, 전체 적 목록을 덮어쓰지 않습니다.

2. 아군 측의 최종 도착 위치 바꾸기

같은 파일의 scene1에서 다음 두 줄이 나란히 있는 마지막 배치 지점을 찾습니다.

검색할 기존 두 줄 · python
stage.unit(0).move(10, 6, 2)
stage.unit(32).move(9, 6, 2)

앞쪽 공백을 유지하며 다음처럼 x만 교환합니다.

기존 두 줄의 내용 교체 · python
stage.unit(0).move(9, 6, 2)
stage.unit(32).move(10, 6, 2)

move의 앞 두 숫자는 도착 x/y입니다. 마지막 인자와 다른 연출은 그대로 둡니다. createMine의 x만 바꾸면 뒤의 등장 연출이 다시 이동시키므로 이번 과제에서는 최종 지점을 수정합니다.

기존 첫 전투 실행 · sh
./gradlew :core:exportScenarioAst :core:processResources
./gradlew :desktop:run --args="--battle --battle-return=R_00"
성공하면 이렇게 보입니다

2턴 등장 연출과 “장보와 장량을 죽여라!” 안내, 선택적 가이드가 끝난 뒤 첫 아군 조작 전에 위치를 봅니다. 아군 0은 (9,6), 우군 32는 (10,6), 적 146은 (10,11), 적 147은 (9,11)에 있습니다.

왜 두 칸을 교환하나요?

임의의 빈칸은 통행 불가이거나 다른 이벤트가 쓰는 자리일 수 있습니다. 첫 과제는 기존에 사용하던 칸을 교환해 좌표와 배치 시점을 배우는 데 집중합니다. 유닛 수·승패 조건·증원은 그대로 유지합니다.
