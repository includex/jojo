Lua로 공격 특성 만들기

필요한 장수·착용 장비에만 동적 규칙을 연결합니다.

이번에 편집할 곳외부 lua-rules.yaml · lua/power.lua
배울 것턴·공격·피격 시점의 계산을 작성합니다.

YAML만으로 충분한 예

검 이름, 기본 공격 수치, 스킬 MP 비용, 기존 회복 효과 배정. 매번 스크립트를 실행할 이유가 없습니다.

Lua가 필요한 예

공격할 때 이번 공격력의 20% 추가, 특정 장수의 턴 종료 회복, 착용 방어구의 피격 피해 3 감소. 기존 이벤트·효과 API 안에서 계산합니다.

실습 A · 이미 준비된 예제를 켜기

  1. content/examples/lua/lua-rules.yaml과 같은 폴더의 lua/ 파일들을 확인합니다. 예제는 기본 게임에서 자동 활성화되지 않습니다.
  2. 아래 명령은 저장소 루트에서 예제 폴더를 외부 규칙 폴더로 지정합니다. 최초 프로그램 준비에는 빌드가 필요하지만, 실행 중 외부 Lua 수정은 재빌드 없이 다음 전투에 반영됩니다.
  3. 예제는 인물 0의 턴 시작 HP +5, 턴 종료 HP +3, 실제 무기 0의 공격력 +10, 실제 방어구 70의 피격 피해 −3을 연결합니다. 장비 과제 착용 실습의 stage.setJoinEquip(0, 2, 0, 2, 0, 0)으로 필요한 장비를 착용시킵니다.
  4. HP가 가득 차 있으면 회복 변화가 보이지 않습니다. 피해를 받은 상태에서 해당 진영의 다음 턴 시작·종료를 확인합니다.
터미널 · 현재 폴더의 Lua 예제 활성화 · sh
./gradlew :desktop:run -Pjojo.rules.dir="$PWD/content/examples/lua"

$PWD는 현재 터미널 폴더입니다. 경로를 설정하는 값은 폴더이며, 그 안에 lua-rules.yaml이 있어야 합니다. 앱 내부의 파일 선택 화면은 아직 없습니다.

등록부는 “누구에게, 언제, 어떤 코드”를 연결합니다

rules 목록의 항목 · 완전한 파일은 예제 링크 참고 · yaml
# 외부 lua-rules.yaml에서 하나의 규칙을 읽는 예
- id: example.weaponPower
  event: ATTACK
  handler: example.power
  parameters: {amount: 10}
  binding: {scope: equipment, id: 0}
항목뜻
id이 규칙의 고유 이름입니다.
event언제 계산할지 지정합니다. ATTACK은 공격자, HIT는 피격자 쪽 연결을 찾습니다.
handler등록부의 scripts 매핑에서 Lua 파일을 찾는 이름입니다.
parametersLua에 전달할 설정입니다. Lua에서는 문자열로 받으므로 숫자는 tonumber로 변환합니다.
bindingcharacter는 특정 인물, equipment는 실제 착용 중인 장비, global은 공통 적용입니다. 가방에 보유하기만 한 장비에는 적용되지 않습니다.

실습 B · 이번 공격력 20% 증가

예제 폴더의 lua/power.lua 내용을 다음으로 바꿉니다. 새 전투부터 적용합니다. 이 예제는 amount 인자를 사용하지 않으므로 YAML의 amount를 바꿔도 결과가 달라지지 않는다는 점을 함께 익힙니다.

power.lua 전체 교체 예제 · lua
return {
  evaluate = function(ctx, params)
    if ctx.phase ~= "POWER" then return {} end
    return {
      {type = "AttackPowerModifier",
       amount = math.floor(ctx.attackPower * 0.2)}
    }
  end
}

피격자 HIT장수 + 착용 장비

core 검증·계산이번 공격에만 반영
이벤트 / 단계쓸 수 있는 효과기억할 점
TURN_START / TURN_ENDHP·MP·선언 자원·지원 상태 변경기존 시작/종료 정산 뒤 해당 활성 진영의 생존·표시 유닛별 처리
ATTACK / HIT + POWERAttackPowerModifier물리는 ATTACK, 마법은 SPIRIT 기반의 이번 공격력 보정
ATTACK / HIT + DAMAGEDamageModifier계산된 HP 피해의 가산 보정

ctx.actor는 공격자, ctx.target은 피격자, ctx.owner는 현재 규칙이 붙은 장수입니다. HIT에서는 owner가 방어자입니다. POWER/DAMAGE는 AI 예상 계산에서도 반복 호출될 수 있으므로 상태를 변경하거나 난수를 사용하지 않습니다.

규칙 계산 연습

아래는 예제 Lua의 산술만 보여줍니다. 실제 게임의 방어력·지형·스킬을 포함한 피해 공식이나 전투 예측기가 아닙니다.

POWER: floor(입력 × 0.2)를 더함

80 + 16 = 96

DAMAGE: 입력 범위 안에서 최대 3 감소

20 − 3 = 17
Lua의 범위와 다시 읽는 시점

파일 변경은 새 전투가 생성될 때 반영됩니다. 진행 중인 전투는 기존 소스를 유지합니다. 파일·네트워크 접근이나 실행 간 Lua 전역 상태 보존은 제공하지 않습니다. 무한 반복·과도한 실행은 제한됩니다. 공격 마법의 HP 피해를 지원하지만 반사·반동 같은 2차 피해, 회복·상태 전용 마법은 새 공격 이벤트가 아닙니다. 전체 시나리오가 Lua로 바뀐 것도 아닙니다.

예제를 끄려면 게임을 닫고 외부 폴더 지정 없이 기본 실행합니다. 환경 변수 JOJO_RULES_DIR를 설정했다면 현재 셸에서 unset JOJO_RULES_DIR로 해제합니다. 예제 폴더 수정 자체는 기본 등록부를 활성화하지 않습니다. 더 많은 효과·제한은 Lua 상세 가이드를 확인하세요.
