실습 A · 기존 작열을 “불꽃탄”으로 바꾸고 배우게 하기

skills/active/0000.yaml에서 아래 세 값을 바꿉니다. type·category·범위·애니메이션 필드는 유지합니다.

부분 수정 · 기존 능동 스킬 0 · yaml
name: "불꽃탄"
mpCost: 5
power: 75

같은 파일의 learnLevels는 병종 → 습득 레벨의 매핑입니다. 현재 주인공의 초기 병종 0도 배우게 하려면 기존 매핑 안에 아래 세 키를 추가합니다. 원래 키들은 유지하고 중복 키가 있다면 그 값을 수정합니다.

병종 0·1·2가 레벨 1부터 배우는 조건 · yaml
# 기존 learnLevels 안에 추가할 항목들
"0": 1
"1": 1
"2": 1

현재 파일은 한 줄 learnLevels: { ... } 형태일 수 있습니다. 그 중괄호 안에 "0": 1, "1": 1, "2": 1,을 기존 항목 앞에 추가하거나, 모든 기존 키를 보존한 채 여러 줄 매핑으로 바꿉니다.

확인할 것

새 게임 전투에서 주인공이 스킬을 배웠는지, 현재 MP가 충분한지, 대상·사거리·날씨·지형 조건을 만족하는지 확인합니다. 원래 화계의 사용 제약은 이름을 바꿔도 유지됩니다.

실습 B · 이미 구현된 턴 시작 HP 회복 배정

skills/assignments/0000.yaml의 기존 skillId: 146, value: 25를 유지하고 아래 항목을 추가합니다. 인물 0에 회복 효과를 연결합니다.

기존 배정 행에 한 줄 추가 · yaml
unit0: 0

효과 146은 기존 턴 회복 효과이며 25는 그 효과의 값입니다. HP를 조금 잃은 상태에서 턴을 진행해 회복을 확인합니다. 원래 장비·병종의 회복도 함께 있을 수 있으므로 여러 효과를 동시에 바꾸지 않습니다.

새 효과를 만들고 싶다면

passive 파일에 새 이름을 넣는 것만으로 효과가 생기지는 않습니다. 기존 효과 조합이면 YAML을 사용하고, 지원된 이벤트·효과 범위의 새로운 계산은 고급 Lua 과제 Lua를 사용합니다. 새로운 화면·대상 처리·효과 종류가 필요하면 core 확장이 필요합니다.
