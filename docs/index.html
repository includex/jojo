조조전 개발 문서

처음 실행하는 개발자부터 엔진·시나리오를 확장하는 개발자까지, 작업 목적에 맞는 문서에서 시작하세요.

01 · 처음 시작하기

환경 준비부터 YAML 수정, 인물 추가, 대사 연결, 실행 확인까지 단계별 실습.

02 · 엔진과 게임 구조

모듈 의존 관계, 책임 경계, AST 실행·경로 탐색·대화 표시 흐름.

03 · 기능 추가하기

인물·거리 장면·전투·장비·스킬을 추가할 때 수정할 계층과 검증 방법.

04 · 시나리오 플랫폼 계약

고정 대사 ID 작성 규칙, 이전 키 호환, ScenarioHostApi v1과 Lua 전환 전 남은 일.

05 · Python API 명세

142개 문서 항목에서 호출 정의·인자·반환값·대기 규칙·사용 예를 검색. 미지원 호출도 구분.

06 · 구현 현황과 제약

현재 콘텐츠 경로, 구현 완료 범위, 검증 기록과 외부 의존성.

어디부터 읽을까요?

첫 작업: 환경 → YAML → 실행전투 수정: 배치·ID → API대사 수정: 고정 ID → 카탈로그엔진 확장: 책임 경계 → 테스트

현재 작성 원본

콘텐츠경로편집 형식
인물·장비·스킬content/characters · equipment · skills개별 YAML + schema.json
장면 진행·전투 배치content/scenarios/R_XX.py · S_XX.py지원 문법 범위의 Python 소스
대사 문장content/scenarios/dialogue-text.json고정 ID → 문장, 이전 키 호환 매핑
모듈 등록content/scenarios/manifest.json기존 형식을 유지한 명시적 등록

Python은 CPython으로 실행되지 않습니다. 생성 AST를 Kotlin 실행기가 처리합니다. Lua 실행기는 아직 없으며, 게임 명령의 언어 독립 계약은 say·delay·choice부터 분리했습니다. 맵·이미지·음원 등에는 외부 복원 프로젝트 의존성이 남아 있습니다.
