개발 가이드

게임 UI와 조작 가이드

명령·인물·저장·설정 화면은 어두운 갈색 프레임, 황동 테두리와 불투명한 양피지 본문을 사용합니다. 기존 도트 아이콘을 유지하고 기능 이름을 함께 표시합니다.

전투 화면

화면동작
상단 상태창전장 이름·날씨·현재 턴/제한 턴이 기본으로 펼쳐집니다. 접기/펼치기로 바꿀 수 있습니다. 메뉴·부대·지도·턴 종료 버튼은 이름으로 구분합니다.
명령창공격·마법·아이템·교환·포위 공격·대기·인물 정보·취소를 표시합니다. 사용 불가한 명령은 흐리게 표시됩니다.
인물 정보현재 인물의 초상화와 실제 병종·장비를 표시합니다. 기본·능력·장비·전략·특기 탭으로 나누고, 닫으면 기존 명령 상태로 돌아옵니다. 정보를 보는 행동은 턴을 소비하지 않습니다.
이동 범위이동 중에는 범위 박스를 숨기고 도착 후 새 위치에서 다시 표시합니다. 이동 취소 시 기존 위치로 돌아갑니다.

저장과 보조 화면

저장·불러오기 목록은 슬롯별 열 너비에 맞춰 표시하고, 긴 이름은 줄임표로 처리합니다. 설정의 체크 상태는 도형으로 표시하며, 도움말에는 실제 조작 방법을 안내합니다. 물품·무공 목록과 상세창은 설명이 겹치지 않도록 목록과 본문을 구분합니다.

공통 대화상자

대화 장면과 전투 장면이 같은 하단 패널·초상화·이름·본문 구성을 사용합니다. 설정은 content/ui/dialogue.yaml의 두 프로필에 있습니다. 논리 화면 크기가 달라 시나리오 좌표는 전투 좌표의 0.86배로 맞췄습니다. 커스텀 표시에서는 원본 래스터 라벨을 사용하지 않습니다.

동시에 진행하는 수치 변화

같은 행동의 체력·기력·장수 경험치·무기 경험치·방어구 경험치가 함께 움직입니다. 예를 들어 피격 후 체력 감소와 방어구 경험치 증가가 동시에 시작합니다. HP의 기존 1.5배속은 유지하며 가장 긴 애니메이션이 끝난 뒤 다음 정산으로 넘어갑니다.

검증

Sol 구현 후 Astra로 실제 화면을 반복 검토했습니다. 전투 UI는 1280×688·960×540 창에서 검사했고, 거점 정보창과 두 장면의 대화상자도 확인했습니다. 발견된 겹침·글리프 누락·클릭 영역·빈 도움말 문제를 수정한 뒤 최종 검토를 통과했습니다.

python3 scripts/smoke_battle_ui.py
python3 scripts/smoke_battle_ui.py scenario

검증 캡처는 verification/build/battle-ui/와 verification/build/scenario-ui/에 생성됩니다.
