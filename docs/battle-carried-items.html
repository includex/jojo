개인 소지품과 교환

공용 가방과 인물의 소지품을 구분합니다. 노지심에게 지급한 고급 금창약은 노지심이 가지고 있으며, 임충에게 전달하면 임충의 소지품이 됩니다.

① 가까이 이동

노지심과 임충을 상하좌우로 인접하게 배치합니다. 대각선은 전달 범위가 아닙니다.

② 교환 선택

노지심의 교환 명령에서 고급 금창약을 선택하고 임충을 선택합니다. 한 번에 한 개를 전달하며 노지심의 행동이 끝납니다.

③ 전달받은 약 사용

임충의 물품 목록에 약이 나타납니다. 사용하면 체력 100을 회복하며 최대 체력을 넘지 않습니다. 약 한 개를 소비하고 행동을 마칩니다.

선택 중 ESC로 취소할 수 있습니다. 공용 가방의 약은 누구나 사용할 수 있지만, 특정 인물에게 배정된 약은 다른 인물의 사용 목록에 나타나지 않습니다. 소지자와 수량은 저장 데이터에 포함됩니다.

시나리오에서 지급하기

stage.giveUnitItem(513, 216, 4)
# 인물 ID, 소모품 ID, 수량(생략 시 1)
# 이 호출은 별도의 획득 대화 없이 해당 인물에게 지급합니다.

수량은 양의 정수이며 현재 개인 소지품은 기존 소모품 ID 범위 150–254를 사용합니다. 반복 실행되는 이벤트에서는 지급 전에 이벤트 실행 여부를 검사해야 합니다. 임충전의 노지심 등장 이벤트는 1회 실행 플래그로 중복 지급을 막습니다.

회복 아이템 정의

# content/equipment/0216.yaml
id: 216
name: "고급 금창약"
itemType: 26
specialType: 3
iconIndex: 87
value: 100
upgradeValue: 0

itemType: 26은 현재 게임의 체력 회복 소모품 유형입니다. value는 회복량이며 upgradeValue: 0이므로 추가 비율 회복은 없습니다.

피해 없는 등장 연출

stage.unit(513).setAction(6, 1, False)
stage.unit(513).setAction(7, 1, False)
stage.unit(513).setAction(6, 1, False)
stage.unit(513).setAction(0, 1, False)

방향 1은 동쪽입니다. 각 공격 동작을 끝까지 재생한 후 대기로 돌아옵니다. setAction은 표시 동작만 바꾸며 실제 전투 피해를 계산하지 않습니다. 등장시킨 유닛에 호출해야 합니다.
