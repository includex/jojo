현재 제약

  • 기타 테이블·맵·이미지·음원은 외부 복원 프로젝트에 의존하며 입력 경로가 하드코딩되어 있습니다.
  • YAML은 데이터 정의입니다. 새 효과 실행 규칙, 이미지 제작, 자동 ID 배정, 라이브 재로딩, 시각적 편집기는 제공하지 않습니다.
  • 장비 효과 그룹은 specialType/itemType으로 조회합니다. 소비 아이템 ID 범위와 compact ID 규칙은 유지됩니다.
  • 시나리오 대사 키는 원본 줄 번호에 의존합니다. manifest와 대사 카탈로그는 별도로 등록합니다.
  • 전체 캠페인 모든 분기와 모든 화면의 픽셀 일치가 검증된 상태는 아닙니다.
