# 도입부 거점 캐릭터 자료

캐릭터는 `jojo_asset/release`의 검토된 원본 PNG를 사용합니다. 선정 이유, 원본 게시글명, SHA-256은 `selection.json`에 기록합니다. 대화 초상화는 변경하지 않습니다.

`python3 scripts/package_linchong_hall_assets.py`는 이동·특수 아틀라스의 48×48 셀을 자른 뒤 48×64 셀의 아래쪽에 그대로 붙입니다. 확대·축소, 색 변경, 자세 생성은 하지 않습니다. `package_linchong_assets.py`에서도 자동 실행합니다.

거점 ABI는 아바타 번호의 `1 + avatarId * 2`가 앞모습, 그 다음 번호가 뒷모습입니다. 방향 2/1은 앞모습, 0/3은 뒷모습이며 1/3은 기존 렌더러가 좌우 반전합니다. 행 0은 대기, 1–2는 걷기, 3–19는 행동 1–17입니다. 행동 6(행8)은 기본적으로 원본 특수 동작 3/4의 몸을 낮춘 자세를 사용하며, 임충은 `subduedPose`에 지정한 이동 아틀라스 8번의 무릎을 낮춘 원본 자세를 사용합니다. 완전히 새로운 무릎 자세를 합성하지 않고 원본 캐릭터의 포즈를 보존합니다.
